# HTML From Zero — 46 animated lessons

An animated HTML course for complete beginners. Markup on the left, the tree / the page / the screen reader on the right, and one plain sentence explaining every step.

**This folder is the HTML course only.** It does not need or include the JavaScript course.

---

## Setup (one minute)

1. Download **all 47 files** — `index.html` plus the 46 lesson files.
2. Put every one of them in **the same folder**. No sub-folders — the prev/next links between lessons are relative paths and only work when the files sit side by side.
3. Open **`index.html`**. That is the hub.

Nothing to install. No server. No internet needed after the first load (fonts come from Google Fonts; without a connection the pages fall back to system fonts and still work).

---

## The controls

| Control | What it does |
|---|---|
| **Run it** | Plays the animation automatically |
| **◀ Back** | One step backwards |
| **Step forward** | One step at a time — the default way to work |
| **Start over** | Back to step 0 |
| **Slow / Normal / Fast** | Playback speed |
| **Scrubber** | Drag to jump to any moment |

Keyboard: **←** back, **→** forward, **space** play/pause.

**How to actually use it:** watch once at normal speed to see the shape of the lesson, then step through manually and try to predict what happens *before* pressing the button. Then rebuild the example from memory in a blank file. HTML rewards typing it out far more than reading it.

---

## What you'll be able to do

Build a complete web page from an empty file. Structure a document so its meaning is clear to browsers, search engines and screen readers. Write links and paths that don't break. Add images that load fast and work for people who can't see them. Build a real form that collects and validates input. Present data in a table readable by both eyes and assistive technology. Control how your page looks in Google and when shared on WhatsApp. Read someone else's HTML and spot what's wrong with it.

**One honest expectation:** HTML alone will not make a page beautiful. HTML is structure and meaning; CSS is appearance. Everything you build here will be *correct* long before it is *pretty*. That is the correct division of labour, and CSS is what to learn next.

## Pacing

**About 11 hours of lessons.** At 30 minutes a day, roughly three and a half weeks.

HTML is genuinely easier than programming. The hard part is not understanding it — it's the discipline of doing it properly when the sloppy version also appears to work.

---

## Known limitations

- **All files must sit in one folder.** Relative links, no server.
- **No exercises yet.** Every lesson teaches and demonstrates; the predict / fix / build practice sets are not built.
- **No projects yet.** The five projects described in the syllabus are not included.
- **No progress tracking.** Nothing is saved between sessions.

## What to learn next

**CSS**, immediately. Then JavaScript. Then a framework — not before. Styling a well-built structure is far easier than fighting a page made of `div`s, which is exactly what this course was for.
