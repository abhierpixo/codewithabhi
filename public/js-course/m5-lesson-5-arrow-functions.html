The four formsall identical in behaviour

        
form 1function double(n) { return n * 2; }The classic. A name, a slot, a body.

          
form 2const double = function (n) { … }Same machine, stored in a box like any other value.

          
form 3const double = (n) => { … }The word function replaced by an arrow.

          
form 4const double = n => n * 2Braces and return dropped. Returns automatically.
